# RESA Portal Navigation Quick Reference

**Portal:** https://resa-school-portal.netlify.app/  
**School:** RHEMA EXPLOITS SCIENCE ACADEMY (RESA)  
**Use:** Existing main RESA portal only. Demo/test records remain demo data and must not be treated as official school records.

## Before signing in
1. Open the RESA portal URL.
2. Select the school portal sign-in option.
3. Enter the registered email or RESA login ID and password issued by the school.
4. If sign-in fails, check the login ID carefully and contact the school administrator. Never share a password in a public message.

## Administrator navigation
- **Dashboard:** overview and shortcuts for the school's operations.
- **Students:** register learners, search by name/admission number, update records and review login-link status.
- **Teachers & Staff:** invitations, approvals, activation and staff records.
- **Parents & Guardians:** parent records, student links and portal activation.
- **Classes / Subjects:** manage class groups and subjects.
- **Attendance:** review and manage daily student attendance.
- **Teaching Assignments:** assign each teacher to the correct class, subject and academic session.
- **Examinations & CBT:** create exams, add questions, review attempts and mark written answers.
- **Results Management:** enter CA/exam marks, review, approve and publish results.
- **Academic Results:** inspect published result records and broadsheets.
- **Fees Management:** create fee types, assign charges, record payments already verified by Finance, and print receipts. Do not record a payment until funds are confirmed.
- **School Services:** open additional operational services.
- **School Messages / Notifications / Announcements:** communicate with authorised school users.
- **School Settings:** manage school profile, academic defaults, user access and account settings.

## Teacher navigation
1. Sign in with the teacher's registered login.
2. Open the teacher dashboard and confirm the displayed name, assigned classes and subjects.
3. Open **Assignments** to create work for an assigned class and subject.
4. Add a clear title, instructions, due date and maximum score.
5. Save as draft, review, then publish.
6. Open **Marking** to review learner submissions and record marks/feedback.
7. Use **Online CBT** only for examinations created and published for the assigned class.
8. Use **Timetable**, **Results**, **Learning Materials** and **School Messages** as available to the teacher's permissions.

## Student navigation
1. Sign in with the RESA login ID/admission number and current password issued by the school.
2. On the Student Dashboard, check the learner's name and school.
3. Open **Assignments** to view work published for the learner's active class and academic session.
4. Select **Open assignment** to read full instructions and open/download any teacher attachment.
5. Enter the response and select **Submit assignment** before the deadline. Check the submission status afterwards.
6. Open **Student CBT** to take an available published examination.
7. Open **My Report Cards** to view results released by the school.
8. Use **Learning Resources**, **Practice Drills**, **School Messages** and **Notifications** for learning and communication.

## Parent / guardian navigation
1. Sign in using the registered parent email, phone/login ID or RESA login ID and password.
2. Confirm that the correct learner(s) are linked to the account.
3. Review fee charges, payments, receipts and outstanding balances.
4. Open published results and attendance information when available.
5. Use School Messages, Notifications and Customer Care to contact the school.

## Important checks and support
- A teacher must publish an assignment before it appears in the learner's published assignment list. The learner's active class and academic session must match the assignment.
- If an assignment is missing, ask the teacher/administrator to verify publication status, class, subject and academic session, then refresh the student assignment page.
- If an attachment does not open, ask the teacher to verify that the file is uploaded and its access permissions allow the intended student to read it.
- If a page displays 404, return to the dashboard and report the exact menu item and URL to the portal administrator.
- Sign out when using a shared device.
- All records created during portal testing are demo/test records until the school explicitly approves the official data transition. Do not delete or overwrite demo records without authorisation.
